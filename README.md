## 🚀 How to Run the Website

### Option 1: Double Click or Open in Any Browser
Just open `index.html` directly in Chrome, Edge, Safari, or Firefox:
```bash
file:///C:/Users/Nakul Nandan/KamieKAM/index.html
```

### Option 2: Run via Local Python Server
In PowerShell or Terminal:
```powershell
cd "C:\Users\Nakul Nandan\KamieKAM"
python -m http.server 8080
```
Then visit: `http://localhost:8080`

## 📸 How to Add Your Own Photos & Song

### 1. Adding Your Photos
Simply place your real photos inside the `images/` folder and name them:
- **First Hangout**: Replace `images/first-hangout.svg` with your photo (e.g., `images/first-hangout.jpg`).
- **Places**: Replace `images/place1.svg`, `place2.svg`, `place3.svg`, `place4.svg`.
- **Gifts**: Replace `images/gift1.svg`, `gift2.svg`, `gift3.svg`.
- **Moments**: Replace `images/hangout1.svg`, `hangout2.svg`, `hangout3.svg`.

### 2. Adding Your Custom Song
Put your favorite song (e.g. `our-song.mp3`) into the `music/` folder:
`KamieKAM/music/our-song.mp3`
